# 🏫 Sistem Jadual Waktu UBK SK Tampasuk 1, Kota Belud
### Sesi Persekolahan 2026 • Guru Praktikal: Cikgu Nurul Syahfirah binti Arjaman

Sistem Pengurusan Praktikum Bimbingan & Kaunseling pintar, berkuasa tinggi, dan sedia untuk diakses secara langsung di internet dengan **Penyegerakan Cloud Masa Nyata (Real-Time Live Sync)**.

---

## 🚀 Panduan Penerbitan Laman Web Percuma (Live 24/7 di Seluruh Dunia)

Untuk membolehkan laman web ini boleh diakses oleh sesiapa sahaja yang mempunyai pautan pada telefon, tablet, atau komputer:

### Kaedah 1: GitHub Pages (100% Percuma & Rasmi) — Disyorkan
1. Buka [GitHub](https://github.com/) dan daftar masuk.
2. Cipta repositori baharu (*New Repository*) bernama `jadual-ubk-sk-tampasuk` (pilih *Public*).
3. Muat naik semua fail dan folder dalam direktori ini (`index.html`, folder `css`, `js`, `data`, dan `img`).
4. Pergi ke **Settings** ➔ **Pages** pada menu repositori anda.
5. Di bawah bahagian **Branch**, pilih `main` (atau `master`) dan folder `/(root)`, kemudian tekan **Save**.
6. Dalam masa 1–2 minit, laman web anda akan **LIVE** di alamat:
   👉 `https://<nama-akaun-github-anda>.github.io/jadual-ubk-sk-tampasuk/`

### Kaedah 2: Vercel / Cloudflare Pages (1 Klik Sedia)
1. Sambungkan repositori GitHub anda ke [Vercel](https://vercel.com/) atau [Cloudflare Pages](https://pages.cloudflare.com/).
2. Tekan **Deploy** (fail `vercel.json` telah disediakan). Laman web terus aktif serta-merta!

## 🌐 Ciri Cloud Real-Time Live Sync

1. **Penyegerakan Masa Nyata (Real-Time)**:
   * Sebarang penambahan sesi, pindaan waktu, pemilihan murid, atau perubahan status sesi oleh Cikgu Nurul akan disegerakkan terus ke cloud secara automatik.
   * Peranti pelawat (Guru Besar, Pensyarah Pembimbing, Guru Kelas, Murid) yang sedang membuka laman web akan menerima kemaskini terkini tanpa perlu memuat semula (*refresh*) halaman!
2. **Pengasingan Peranan (Kaunselor vs Pelawat)**:
   * **Pautan Awam / Murid / Guru (`?role=viewer`)**: Membolehkan pelawat menyemak jadual, mencari slot bukan teras, dan mencetak slip/borang tanpa risiko mengubah atau memadam sesi kaunselor.
   * **Pautan Kaunselor (`?role=admin`)**: Akses penuh pentadbir dilindungi dengan PIN keselamatan `2026`.
3. **Penyegerakan Rentas-Tab & Luar Talian (Offline-First)**:
   * Menyokong `BroadcastChannel` untuk segerak 0ms antara tab yang terbuka pada peranti yang sama.
   * Menyimpan salinan tempatan pada `localStorage` sekiranya tiada sambungan internet dan menyegerak semula sebaik sahaja talian pulih.

## 📜 Format Cetakan Borang Rasmi IPGM 100% Menepati Standard

* **Lampiran IPGM 07 (m/s 532)**: Borang Rekod Sesi Perkhidmatan B&K (**A4 Potret**).
* **Lampiran IPGM 09 (m/s 534–536)**: Analisis Rekod Sesi B&K (**A4 Potret, 3 Halaman Berturutan**).
* **Lampiran IPGM 10 (m/s 537)**: Borang Rumusan Sesi Kaunseling SULIT (**A4 Landskap, 31 Lajur Matriks**).
* Lengkap dengan logo rasmi **Jata Negara Malaysia** di bahagian kepala surat (*letterhead*).

* Mengandungi maklumat lengkap 422 murid SK Tampasuk 1 (Nama Penuh, No. Kad Pengenalan, Kelas 1A–6B & Prasekolah, Jantina L/P, Kaum Rasmi APDM M/C/I/L & Asal, dan Penjaga).
* Pemilihan klien pantas tersedia secara terus pada setiap kad sesi dalam jadual mingguan.
